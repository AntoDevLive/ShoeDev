# 👟 ShoeDev

ShoeDev es una aplicación de comercio electrónico desarrollada como proyecto Full Stack, diseñada para simular un entorno de venta online real. El proyecto combina tecnologías modernas de frontend y backend para ofrecer una experiencia de usuario fluida, gestión eficiente de datos y una arquitectura preparada para crecer y adaptarse a nuevas funcionalidades.

## 🚀 Tecnologías utilizadas

### Frontend

* HTML5
* Tailwind CSS
* JavaScript

### Backend

* PHP

### Base de Datos

* MySQL

### Herramientas

* Node.js
* NPM

---

## ✨ Funcionalidades

* Visualización dinámica de productos.
* Gestión de catálogo.
* Carrito de compra.
* Persistencia de datos mediante MySQL.
* Interfaz responsive adaptada a móviles, tablets y escritorio.
* Navegación intuitiva enfocada en la experiencia de usuario.
* Comunicación entre frontend y backend para la gestión de datos.

---

## 🎯 Objetivos del proyecto

ShoeDev fue desarrollado para poner en práctica conceptos clave del desarrollo web Full Stack, replicando funcionalidades habituales de una tienda online profesional.

Entre los aspectos trabajados destacan:

* Desarrollo de aplicaciones web completas.
* Diseño responsive y experiencia de usuario.
* Gestión de bases de datos relacionales.
* Integración cliente-servidor.
* Organización y escalabilidad del código.
* Resolución de necesidades reales mediante software.

## 🛠️ Instalación

### Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
```

### Acceder al proyecto

```bash
cd ShoeDev
```

### Instalar dependencias

```bash
npm install
```

### Ejecutar la aplicación

Levantar el servidor local (XAMPP, Laragon o similar) y acceder al proyecto desde el navegador.
